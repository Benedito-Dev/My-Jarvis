# 0002 · Python 3.12

- **Status:** ✅ Aceita
- **Data:** 2026-10-16

## Contexto

Precisamos de uma linguagem com bom suporte a câmera, visão computacional, voz e IA,
e de uma versão compatível com essas bibliotecas.

## Decisão

**Python 3.12.**

## Alternativas consideradas

- **Python 3.13+:** mais novo, mas as libs de visão (dlib/`face_recognition`)
  ainda têm lacunas de compatibilidade.
- **Python 3.9 (o do sistema macOS):** antigo, sem suporte ativo.

## Consequências

- ✅ Compatibilidade garantida com OpenCV e dlib
- ⚠️ Revisar quando as libs de visão suportarem bem versões mais novas
