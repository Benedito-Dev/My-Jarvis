# 🧭 Visão

## O que é

Um **assistente pessoal de desktop** (estilo Jarvis) que roda nas três máquinas
do dono — **macOS, Linux e Windows** — e ganha novas **habilidades** aos poucos.

A primeira habilidade é o **desbloqueio por reconhecimento facial**:

```
"Por favor, aproxime seu rosto"  ──►  📷  ──►  ✅ "Bem-vindo, Benedito"
```

## Escopo

O escopo é **aberto de propósito**. Ainda não sabemos tudo o que o Jarvis
vai fazer e tudo bem. Ele cresce uma habilidade por vez.

Ideias futuras (nada prometido):

- 🗣️ Falar e ouvir comandos de voz
- 🤖 Conversar usando um modelo de IA
- 🖥️ Abrir apps e automatizar tarefas no Mac

## Princípios de trabalho

1. **Passos pequenos que terminam.** Cada passo precisa funcionar e ser visível.
2. **Valorizar cada vitória.** Passo concluído = commit + marcação no roadmap.
3. **Simples antes de bonito.** Primeiro funciona no terminal, depois ganha interface.
4. **Não construir para o futuro imaginado.** Só criamos estrutura quando ela
   for necessária de verdade.

## Fora de escopo (por enquanto)

- Segurança de nível bancário (uma foto pode enganar o desbloqueio, e isso é aceito na v1)
- Versão web ou mobile
